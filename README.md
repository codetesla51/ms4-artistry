# MS4 Artistry

Marketing site for MS4 Artistry, a makeup and content studio in Tanke, Ilorin, Kwara State.

## Preview

Open `index.html` directly in a browser, or serve the folder locally:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Stack

- Single-file HTML, CSS, and vanilla JavaScript
- No framework, package manager, or build step
- Responsive layout with a mobile menu and swipeable studio rates
- Booking is by phone or WhatsApp only

## Assets

All images, the studio tour video, and the poster live in `assets/`. The hero portrait has 640w and 1122w variants for mobile and desktop.
